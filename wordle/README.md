# 🎮 Wordle Plus

### A Flutter-Based Word Puzzle Game

Wordle Plus is a word-guessing game developed using **Flutter and Dart**, inspired by the popular Wordle game. Players try to identify the hidden word through a series of guesses, using visual feedback to refine their answers.

## 🚀 Play the Game

🔗 **[Play Wordle Plus – Live Demo](https://wordle-plus-4692a.web.app)**

🌐 Hosted on Firebase

## ✨ Features

- Interactive word-guessing gameplay
- User-friendly and responsive interface
- Visual feedback for guessed letters
- Keyboard-based letter input
- Cross-platform development using Flutter
- Web deployment through Firebase Hosting

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Flutter | Cross-platform UI development |
| Dart | Application logic |
| Firebase Hosting | Web application deployment |

## 📸 About the Project

Wordle Plus combines logical reasoning, vocabulary, and interactive gameplay into a simple and engaging application. The project demonstrates Flutter application development, UI design, game logic implementation, and web deployment.

## 💻 Run Locally

To run the project on your local machine:

### 1. Clone the repository

```bash
git clone https://github.com/Parna-tech32/portfolio.git
```

### 2. Navigate to the project directory

```bash
cd portfolio/wordle
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```

To run the application in a web browser:

```bash
flutter run -d chrome
```
